## 🎮 How to Use

1. **Enter your Domain name** in the text field
2. **Select a Domain Type** (Void, Flame, Ice, etc.)
3. **Click EXPAND** or press Enter
4. **Experience your Domain Expansion!**
5. Press **Escape** or click **Exit Domain** to return
